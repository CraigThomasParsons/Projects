## Livewire & UI State

- I used **Livewire to manage UI state server-side**, including modal open/close behavior.
- UI interactions (clicks, key presses) trigger PHP methods instead of JavaScript handlers.
- Livewire uses a small JavaScript runtime for DOM diffing, but **all state and logic live in PHP**.
- I implemented:
  - `wire:click` for actions
  - `wire:model` for two-way form binding
  - `wire:keydown.escape` for accessibility-friendly keyboard handling

**How I explain it:**  
> “Livewire uses a thin JavaScript layer to sync DOM updates, but all UI state and behavior live on the server.”

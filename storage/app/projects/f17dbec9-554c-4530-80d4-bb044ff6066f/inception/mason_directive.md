# Mason Backlog Generation Directive

SYSTEM: You are Mason, an expert agile architect. Your job is to translate this Lean Inception MVP into Epics, Stories, and Tasks.

## Project Vision
For developers and product teams who need a seamless, self-improving development process. It solves the problem of context overload, "idea drift", and manual handoffs in software engineering by using an event-driven team of bounded A.I. agents (Piper, Mason, Vera, Deckard). The outcome is a continuous Test-Yes-Ship (TYS) loop resulting in fully automated, behavior-driven Pull Requests ready for human review. Now is the time because LLMs are finally capable of acting as autonomous teammates, provided they are given strict, deterministic infrastructure rather than unstructured chat interfaces.
For the modern developer who suffers from task overflow and context switching, the Factory Workbench Auto Pipeline is a Context-Controlled Development Factory that orchestrates a dedicated team of A.I. agents through an automated TYS loop to completely autonomously deliver production-ready Pull Requests.


## The 'Must Have' MVP Checklist
- [ ] "The Team" Page (Agent Roster): A dedicated ChatProjects UI feature acting as the structural home for all agents. Includes TeamMember profiles with explicit fields for limitations, responsibilities, and strengths to prevent "idea drift".
- [ ] Mason → Ollan Handshake Protocol (v1.0): The strict deterministic infrastructure where Mason generates an immutable TaskPacket and Ollan executes it exactly once in a sandboxed environment without self-reflection.
- [ ] Sprint completion: Run a sprint and loop through each feature/ticket until it done

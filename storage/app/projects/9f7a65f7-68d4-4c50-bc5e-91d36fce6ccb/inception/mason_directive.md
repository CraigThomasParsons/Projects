# Mason Backlog Generation Directive

SYSTEM: You are Mason, an expert agile architect. Your job is to translate this Lean Inception MVP into Epics, Stories, and Tasks.

## Project Vision
Create a self-hosted portfolio and blog to showcase personal projects and tools, with a focus on stability, simplicity, and expandability.

## The 'Must Have' MVP Checklist
- [ ] Self-Hosted Portfolio: A simple and expandable portfolio website to showcase personal projects and tools.
- [ ] JSON-Driven Project Data: A JSON file to store project data, making it easy to update and showcase projects.
- [ ] DigitalOcean VPS: A virtual private server to host the portfolio and blog, providing stability and simplicity.
- [ ] Cloudflare DNS: A DNS service to manage domain names and provide a secure and fast connection.

INSTRUCTIONS: For each item in the checklist above, generate a robust User Story and list the technical Tasks required to implement it.

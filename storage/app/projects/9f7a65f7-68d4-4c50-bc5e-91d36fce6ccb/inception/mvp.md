# MVP Canvas (MoSCoW)

## Must Have (Core to the MVP)

- **Self-Hosted Portfolio**
  - A simple and expandable portfolio website to showcase personal projects and tools.
- **JSON-Driven Project Data**
  - A JSON file to store project data, making it easy to update and showcase projects.
- **DigitalOcean VPS**
  - A virtual private server to host the portfolio and blog, providing stability and simplicity.
- **Cloudflare DNS**
  - A DNS service to manage domain names and provide a secure and fast connection.

## Should Have (Important, but not vital)

- **Blog**
  - A blog to share knowledge, experiences, and ideas related to personal projects and tools.

## Could Have (Nice to have)

- **Live Tools Page**
  - A page to showcase live tools and services, providing a way to demonstrate complex projects.

## Won't Have (Out of scope for this version)

*None specified.*

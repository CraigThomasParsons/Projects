# MVP Canvas (MoSCoW)

## Must Have (Core to the MVP)

- **Radial Menu Setup**
  - Allow users to set up a radial menu that works with directional keys on the Azeron Cyro and Cyborg controllers.

## Should Have (Important, but not vital)

- **Steam Input Integration**
  - Integrate the radial menu system with Steam Input for seamless compatibility across Steam games.
- **Custom Profile Saving**
  - Enable users to save custom radial menu profiles per game for easy switching and personalization.

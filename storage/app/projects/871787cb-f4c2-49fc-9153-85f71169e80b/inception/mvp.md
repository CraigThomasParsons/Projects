# MVP Canvas (MoSCoW)

## Must Have (Core to the MVP)

- **2D Graph Visualization**
  - Visualize the pipeline as a 2D graph with nodes and edges

## Should Have (Important, but not vital)

- **Job Animation**
  - Animate job tokens moving along edges in the pipeline graph
- **Real-time Updates**
  - Update the pipeline visualization in real-time using a sidecar event streamer

## Could Have (Nice to have)

- **3D Walkable Factory**
  - Visualize the pipeline as a 3D walkable factory

## Won't Have (Out of scope for this version)

*None specified.*
